# Field OS — public YC demo

Phone-ready field quoting for Broward pool shops. Live: https://gizaom.github.io/field-os-demo/

Source is private: [gizaom/field-os](https://github.com/gizaom/field-os). This repo is a compact static demo only.

Default shop: **Pembroke Pool Service**, Pembroke Pines. No auth. Jobs, pricebook, and shop stay in the browser (localStorage + IndexedDB). Camera and mic need HTTPS — GitHub Pages provides that.

Open on a phone. New job → pad photos → ~90s voice note → scene-suggested line items → branded estimate + Jobber paste.
